Key information

Hirai / Maison de cinq 2F・3F

〒132-0035 東京都江戸川区平井5丁目58-2 Maison de cinq 2・3F

Entrance keybox

The keybox is attached to the entrance door.

玄関ドアにキーボックスがあります。

Keybox code / キーボックス番号
9125
  1. Find the keybox on the entrance door.
  2. Set the code to 9125.
  3. Open the keybox and take out the key.
  4. After opening the door, close the keybox securely.

玄関ドアのキーボックスを開け、鍵を取り出してください。使用後はキーボックスを確実に閉めてください。
